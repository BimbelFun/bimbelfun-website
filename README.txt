BIMBEL FUN — Website versi pertama (frontend statis)

CARA MENCOBA
1. Ekstrak folder bimbelfun-website.
2. Buka index.html dengan browser (Chrome, Safari, Firefox, Edge).
3. Pastikan perangkat terhubung internet untuk memuat font Google Fonts.

ISI VERSI PERTAMA
- Halaman utama responsif untuk HP dan desktop.
- Bagian program belajar tanpa harga tetap.
- Tombol WhatsApp ke 085801183555 dengan pesan awal.
- Informasi alamat dan tautan Google Maps yang diberikan.
- Pengalih bahasa Indonesia/Inggris.

CATATAN PENTING
- Ini adalah prototipe frontend statis, belum memiliki backend/database, login Owner/Admin/Guru,
  dashboard, pengelolaan konten, atau sistem pembayaran.
- Domain bimbelfun.id belum dibeli/diverifikasi dan website belum dipublikasikan.
- Logo asli belum disematkan pada paket ini; identitas teks/monogram sementara digunakan.
- Isi, desain, harga, dan program masih dapat direvisi sebelum dipublikasikan.
